# Checklist final da Biblioteca

## Pesquisa

- [ ] A busca padrão abre em **Título**.
- [ ] A pesquisa por título retorna resultados relacionados ao título informado.
- [ ] A pesquisa por autor funciona.
- [ ] A busca geral funciona.
- [ ] O botão mostra **Pesquisando...** sem cortar o texto.
- [ ] A paginação avança e retorna corretamente.
- [ ] Capas ausentes usam o placeholder de livro.

## Biblioteca

- [ ] É possível adicionar um resultado aos lidos.
- [ ] É possível adicionar um resultado ao Quero ler.
- [ ] O cadastro manual funciona.
- [ ] A edição de um livro funciona.
- [ ] A exclusão e o botão Desfazer funcionam.
- [ ] Os dados continuam após atualizar a página.

## Páginas

- [ ] Favoritos abre e exibe livros favoritos.
- [ ] Autores favoritos abre e permite pesquisar pelo autor.
- [ ] Lidos permite pesquisar e ordenar.
- [ ] Quero ler permite marcar um livro como lido.
- [ ] O menu destaca a página atual.

## Backup

- [ ] Exportar backup baixa um arquivo `.json`.
- [ ] Importar o arquivo exportado solicita confirmação.
- [ ] Um JSON incorreto é recusado.
- [ ] Após importar, os dados restaurados aparecem nas páginas.

## Responsividade e acessibilidade

- [ ] O layout funciona em 360 px de largura.
- [ ] O layout funciona em tablet.
- [ ] O layout funciona em computador.
- [ ] O menu hambúrguer abre, fecha e responde à tecla Escape.
- [ ] É possível navegar pelos controles usando Tab.
- [ ] Botões e campos apresentam foco visível.

## Publicação

- [ ] `config.js` não está no repositório.
- [ ] A chave da API possui restrições adequadas.
- [ ] O README contém uma imagem atual do projeto.
- [ ] O link publicado abre todas as páginas.
- [ ] O console do navegador não apresenta erros inesperados.
